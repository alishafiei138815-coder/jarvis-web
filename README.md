# JARVIS Web Assistant V2

Run:
1. python -m venv .venv
2. Activate the environment.
3. pip install -r requirements.txt
4. python app.py
5. Open http://127.0.0.1:5000

V2 adds Notes, Reminders, dashboard statistics, PWA manifest/service worker, responsive UI, browser voice input, and a larger modular API.
For iPhone/iPad on the same Wi-Fi, start the server with host 0.0.0.0 and open the computer's LAN IP on the device.
